> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make the portable baseline evaluator and multi-seed workflow scientifically donor-equivalent and executable end to end from the committed panel.

**Architecture:** Keep evaluation math in `scenarioflow.evaluation`, numerical recipe/data preparation in `scenarioflow.training`, and DAG planning/execution in `scenarioflow.workflows`. Evaluation receives two explicit scenario decks: the matched model deck and a deck generated from deterministically shuffled histories. Training checkpoints carry recipe, validation, migration, and panel provenance; node manifests seal those records.

**Tech Stack:** Python 3.13, NumPy, PyTorch, pytest, uv.

**Spec:** `.superpowers/sdd/release-plan/task-3-brief.md` and controller Task 3 fix-round-3 review.
